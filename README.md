# Hands-on Introduction to Python from the University of Utah Center for High Performance Computing

Welcome to _Hands on Introduction to Python_! This repository contains resources for the University of Utah Center for High Performance Computing's Python course. This is a hands-on introduction to the Python language for beginners.

The materials in [notebooks/](notebooks/) are intended to be viewed and run as marimo notebooks.

## Notes

The NumPy and SciPy lecture materials are available in a [separate repository](https://github.com/chpc-uofu/intro-numpy).
